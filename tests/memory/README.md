# Проверки памяти

`test_memory.cpp` содержит семь небольших сценариев для `UniquePtr`, `SharedPtr`
и `DynamicArray`: перемещение и копирование владельцев, `reset`, `release`,
массивы, доступ к элементам и расширение буфера. Для проверки уничтожения
объектов используется существующий `LifetimeCounter` из `tests/utils`.
Проверки остаются активными и в Release; ошибка возвращает ненулевой код выхода.

## Сборка без GoogleTest и бенчмарков

```bash
cmake -S . -B build/memory -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=OFF -DBUILD_BENCHMARKS=OFF
cmake --build build/memory --target memory_tests
./build/memory/tests/memory/memory_tests
```

Если `BUILD_TESTING=ON`, обычный `memory_tests` также включается в CTest.
Для отключения всех целей памяти используйте `-DBUILD_MEMORY_TESTS=OFF`.

## Valgrind / Memcheck

Нужен установленный Valgrind. После установки повторите конфигурацию CMake,
чтобы она нашла инструмент, затем запустите:

```bash
cmake --build build/memory --target check_valgrind
```

Цель запускает обычный `memory_tests` с подробной проверкой утечек и поиском
источников неинициализированных значений. Ошибки памяти и утечки категорий
`definite`, `indirect`, `possible` приводят к ошибке сборочной цели.
`still reachable` выводится для информации: память ещё доступна через указатели
при завершении процесса, поэтому сама по себе эта категория не считается ошибкой.
Если Valgrind отсутствует, цель завершается с понятным сообщением и ненулевым кодом.

## ASan + UBSan + проверка утечек

Для GCC и Clang предусмотрен отдельный исполняемый файл
`memory_tests_sanitized`, который автоматически собирается и запускается:

```bash
cmake --build build/memory --target check_sanitizers
```

ASan проверяет обращения к памяти, UBSan — неопределённое поведение.
Проверка утечек включена через `ASAN_OPTIONS=detect_leaks=1`;
ей нужна платформа с поддержкой LeakSanitizer. При обнаружении ошибки запуск
завершается с ненулевым кодом. В отчётах доступны отладочные строки и стек вызовов.
Санитайзеры не добавляются к приложению, функциональным тестам или бенчмаркам.

Запускайте Valgrind и санитайзеры отдельно. Для Valgrind используется
`memory_tests`, для санитайзеров — `memory_tests_sanitized`.
LeakSanitizer не работает под `ptrace` (например, в некоторых песочницах или
под отладчиком); в такой среде нужно запускать цель вне неё, сохраняя проверку утечек.
